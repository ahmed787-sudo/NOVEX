# NOVEX

متجر متعدد الأقسام، مع كتالوج يبدأ فارغًا دون منتجات أو أسعار.

## الملفات
- `index.html`: الصفحة الرئيسية والأقسام.
- `style.css`: هوية بصرية متجاوبة.
- `app.js`: تعريف الأقسام وتجهيز نقطة تكامل API.

## الأقسام
إلكترونيات، موبايلات، كمبيوتر، أزياء، أحذية وشنط، جمال وعناية، منزل ومطبخ، أثاث وديكور، أجهزة منزلية، رياضة، ألعاب، أطفال، كتب، سيارات، حيوانات أليفة، سوبر ماركت، مكتب وأعمال، هدايا.

## المنتجات والأسعار
الكتالوج فارغ افتراضيًا. لا توجد منتجات تجريبية ولا أسعار ثابتة في الواجهة.

## ربط API
يوجد إعداد مبدئي في `app.js` باسم `API_CONFIG`:
- `enabled`: يظل false حتى تحديد مزود API.
- `baseUrl`: عنوان خدمة API.
- `productsPath`: مسار المنتجات.

لم يتم تنفيذ طلبات API فعلية بعد، لأن مزود المنتجات وتوثيق طريقة المصادقة وشكل الاستجابة لم يتم تحديدهم. لا تضع API keys سرية في JavaScript يعمل داخل المتصفح. يجب تمريرها من خادم وسيط آمن.

## التشغيل
افتح `index.html` في متصفح، أو انشر المستودع باستخدام GitHub Pages.
