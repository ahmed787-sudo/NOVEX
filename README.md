# NOVEX Store

واجهة متجر إلكتروني عربية متجاوبة لعرض منتجات متنوعة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع باستخدام GitHub Pages.

## الملفات
- `index.html`: هيكل المتجر.
- `style.css`: التصميم المتجاوب.
- `app.js`: المنتجات التجريبية والبحث والتصنيفات وسلة التسوق.

## ملاحظات مهمة
- المنتجات والأسعار داخل `app.js` بيانات تجريبية ويمكن تعديلها.
- السلة محفوظة في متصفح الزائر باستخدام Local Storage.
- زر إتمام الطلب تجريبي فقط. لا توجد حاليًا قاعدة بيانات أو لوحة تحكم أو دفع إلكتروني أو نظام شحن.
- لا تضع مفاتيح API أو بيانات سرية داخل ملفات الواجهة الأمامية.
